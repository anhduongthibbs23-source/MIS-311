# MIS 311: Introduction to Business Analytics 📊

Welcome to my **MIS-311** repository! I am an undergraduate student majoring in **Supply Chain Management**, and this space showcases my journey in applying business analytics to solve real-world operational challenges.

## 📁 Project Overview: Supermarket Sales EDA
This repository contains my first assignment for the course, focusing on **Exploratory Data Analysis (EDA)**. 

### 🎯 Objective
The goal of this project is to analyze the `10_Supermarket Sale` dataset to identify purchasing patterns, evaluate product category performance, and derive actionable business insights that can help optimize retail inventory and targeted marketing.

### 🛠️ Tools Used
*   **Data Cleaning & Analysis:** WPS Sheets / Microsoft Excel (Descriptive Statistics, Data filtering, Deduplication).
*   **Data Visualization:** Bar charts to map revenue against product categories.

### 📂 Files in this Repository
*   `10_Supermarket Sale.xlsx`: The raw dataset containing 253 transaction records across 3 branches.
*   `Supermarket_Sales_EDA_Report.docx`: The final report detailing the data cleaning process, descriptive statistics, visual charts, and key business insights.

*Feel free to explore the report to see how data-driven decisions can enhance retail supply chain efficiency!*
